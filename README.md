# UI-автотесты учебного интернет-магазина

Итоговый проект курса Stepik «Автоматизация тестирования с помощью Selenium и Python».

Тесты проверяют учебный интернет-магазин:
https://selenium1py.pythonanywhere.com/

Проект использует Page Object Model: действия и проверки страниц вынесены в отдельные классы, локаторы хранятся отдельно от тестов.

## Стек

- Python 3.13
- Selenium 4.26.1
- pytest 8.3.3

## Проверяемые сценарии

- Переход на страницу входа с главной страницы и страницы товара.
- Наличие ссылки на вход, формы входа и формы регистрации.
- Регистрация пользователя с уникальным email и проверка авторизации.
- Добавление товара гостем и зарегистрированным пользователем.
- Соответствие названия и цены товара данным в сообщениях после добавления.
- Добавление товара с параметризацией по 10 промопредложениям.
- Отсутствие товаров и наличие сообщения о пустой корзине.
- Проверки отсутствия и исчезновения сообщения об успешном добавлении.

Для каждого теста создаётся отдельная сессия браузера. Ожидания реализованы через WebDriverWait.

## Структура проекта

- `pages/base_page.py` — общие методы страниц и ожидания.
- `pages/main_page.py` — главная страница.
- `pages/login_page.py` — вход и регистрация.
- `pages/product_page.py` — страница товара.
- `pages/basket_page.py` — корзина.
- `pages/locators.py` — локаторы элементов.
- `conftest.py` — фикстура браузера и параметры запуска.
- `test_main_page.py` — проверки с главной страницы.
- `test_product_page.py` — проверки со страницы товара.
- `pytest.ini` — настройки pytest и маркеры.
- `requirements.txt` — зависимости.

## Установка

Необходимы Python и установленный Google Chrome или Firefox.

Пример для Windows PowerShell из папки проекта:

```powershell
python -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install -r requirements.txt
```

Для работы Selenium может потребоваться доступ к сети для получения подходящего драйвера браузера.

## Запуск

Весь набор в Chrome:

```powershell
python -m pytest -v --tb=short -rx
```

Только тесты, отмеченные для проверки:

```powershell
python -m pytest -v -m need_review
```

Один тест:

```powershell
python -m pytest test_main_page.py::test_guest_can_go_to_login_page -v
```

Проверка сбора без запуска браузера:

```powershell
python -m pytest --collect-only -q
```

В фикстуре предусмотрены параметры браузера и языка:

```powershell
python -m pytest --browser_name=firefox --language=en -v
```

По умолчанию используются Chrome и английский язык. Проверка текста пустой корзины привязана к английскому языку, поэтому произвольная смена языка может потребовать изменения проверки.

## Ожидаемые падения

Три учебных сценария отмечены `xfail`:

| Сценарий | Причина |
| --- | --- |
| Добавление с `promo=offer7` | Название книги в сообщении не совпадает с названием товара |
| Отсутствие сообщения после добавления | Сообщение присутствует; сценарий сохранён как учебный пример ожидаемого падения |
| Исчезновение сообщения после добавления | Сообщение не исчезает за 4 секунды |

`XFAIL` означает ожидаемое падение, а не успешное выполнение проверки. Включён строгий режим: неожиданный успех такого теста требует пересмотра отметки.

Чтобы увидеть фактические ошибки этих сценариев:

```powershell
python -m pytest --runxfail -v --tb=short
```

## Результаты проверки

При локальном полном прогоне 30 октября 2026 года в Chrome на Windows с Python 3.13.0 получен результат:

**18 passed, 3 xfailed.**

После последующей правки ожидания отсутствия товара отдельно проверены оба сценария пустой корзины: **2 passed**.

Запуск в Firefox предусмотрен конфигурацией, но в ходе этой доработки не проверялся.

## Ограничения

Проект обращается к внешнему учебному сайту. Доступность сети и изменения сайта могут влиять на результаты.

Сценарии регистрации создают новые учебные учётные записи; автоматическое удаление этих записей не реализовано.
